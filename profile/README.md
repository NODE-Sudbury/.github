## Who we are

NODE is an Ontario not-for-profit that supports careers in software development across Northern Ontario. We run professional growth events, help companies find and grow tech talent in the North, and connect developers, employers and government partners in one network.

Everyone is welcome: students, self-taught developers, professionals, founders and the curious. You do not need to be an expert, and you do not need to live in Sudbury to take part.

Every public repository, with its contributors and commit activity, is listed on [nodesudbury.com/open-source](https://nodesudbury.com/open-source). It updates daily, so your commits show up there once they reach a project's main branch.

## Contributing

1. Read the `CONTRIBUTING.md` of the repository you want to work on.
2. Fork it and branch off `dev`. Open your pull request into `dev`, never `main`.
3. You do not need any keys. The website runs on its sample data, and anyone working on sign-in or the admin side can build a private local database with `npm run db:local`.
4. Checks run on every pull request, and a maintainer reviews it.

We follow our [Code of Conduct](https://nodesudbury.com/coc) in every repository, at events and in Discord.
